# Check fomo

[English](README.md) · **Русский**

Следите за трейдерами NEAR в реальном времени, как в FomoApp. Check fomo показывает каждую покупку, продажу и перевод любого NEAR-кошелька постом с хешем транзакции. Есть PnL-борд за 24 часа, 7 и 30 дней, рейтинг 100 лучших мем-трейдеров NEAR, подключение кошелька, подписки на трейдеров и живая лента подписок с громкими оповещениями.

Главная страница — только поле поиска. Кошелёк открывается, когда вы вводите адрес. Ссылку на конкретный кошелёк можно сохранить: адрес сайта с `?account=имя.near`.

Создано [@Checker1crypto](https://x.com/Checker1crypto).

## Рейтинг лучших трейдеров

В левой колонке страницы любого кошелька — 100 самых прибыльных мем-трейдеров NEAR, как в FomoApp.

- **Периоды:** 24 часа, 7 или 30 дней. В период попадают позиции, открытые в нём, каждая со своим полным результатом: реализованный плюс нереализованный по текущей цене, в долларах. Так же считает и сам Nearly в своём рейтинге.
- **Сортировка по PnL** (прибыль в долларах) или по **ROI** (прибыль относительно вложенного; учитываются кошельки, вложившие за период от $25).
- **В каждой строке:** место, кошелёк, PnL, ROI, число сделок и площадки, на которых заработана прибыль. При наведении — реализованный и нереализованный PnL и лучший токен. Клик по строке открывает кошелёк.
- **Кнопка «Обновить»** заново загружает все данные (примерно 10–15 секунд, с полосой прогресса); пока идёт обновление, на экране остаётся прежний рейтинг. Рейтинг кэшируется в браузере и сам обновляется при открытии, если ему больше 10 минут.
- **Только прибыльные кошельки.** Протокольные аккаунты (солверы NEAR Intents, роутеры, контракты лаунчпадов и токенов) исключены.

Откуда цифры (ничего не считается дважды):

- **Токены Nearly** (`*.nearlytrade.near`) — рейтинг самого Nearly (`/api/traders`, топ-100 за период). Для кошельков вне этого топа, которые заработали на других площадках, результат на Nearly берётся из `/api/trader/{аккаунт}` по тому же правилу периода, чтобы не потерять их убыток на Nearly.
- **Все остальные мемы** (Hoot, Shore, Meme Cooking, tkn.near, Token0, NearPad, Neara, NearBased, лаунчпад Intear, AIdols и другие, а также классические мемы на Rhea: SHITZU, NEKO, LONK, GEAR и др.) — расчёт прямо в браузере по ончейн-свопам из индексатора [Intear](https://docs.intear.tech/docs/events-api/historical). Из списка пулов Rhea берутся 20 самых торгуемых таких токенов (объём за 24 часа), по их последним свопам видно, кто ими торгует, а для 60 самых активных из этих кошельков дополнительно читаются их собственные последние свопы. Позиции считаются как во вкладке «Позиции» (средняя цена входа, повторная покупка после полного выхода — новая позиция). Продажа без известной покупки до неё не учитывается: её себестоимость неизвестна. Свопы за RHEA, ZEC, USDC и другие токены пересчитываются в NEAR по текущей цене.

## Соцфункции: кошелёк, профиль, подписки

- **Подключение кошелька.** HOT, Meteor, Intear, MyNearWallet, Ledger, OKX, Nightly и другие кошельки NEAR через официальный лёгкий коннектор [NEAR Connect](https://github.com/hot-dao/near-selector). Check fomo только читает ваш адрес: никаких транзакций и подтверждений. Можно войти и без кошелька, просто введя свой аккаунт. Код кошельков работает только на отдельной странице `connect.html`, а основное приложение сохраняет строгую Content-Security-Policy.
- **Профиль.** На странице любого кошелька плитки PnL за 24 часа, 7 и 30 дней (клик открывает подробную сводку), имя и аватар из NEAR Social, если они есть. Своя страница помечена «Это вы», на ней есть кнопка «Отключить».
- **Подписки.** На каждом кошельке есть кнопка «Подписаться»; без подключения она проведёт через вход и подпишет сразу после него. Подписки хранятся в браузере для каждого подключённого аккаунта. Можно импортировать подписки из NEAR Social (`social.near`, до 50 за раз).
- **Лента подписок** (справа внизу) — живые сделки кошельков из подписок:
  - вкладка «Лента»: сами сделки, со звуком и уведомлениями о свежих (отключается в настройках);
  - вкладка «Кошельки»: управление подписками.

  Каждый кошелёк из подписок по очереди получает одну дешёвую проверку баланса; его транзакции читаются только когда баланс изменился, плюс страховочное обновление раз в 2 минуты. Поэтому лента не упирается в лимиты публичных API даже при десятках подписок.
- **Вкладка «Позиции»** (сразу после «Все»), как в FomoApp. Сверху сводка: реализованный и нереализованный PnL, винрейт по закрытым позициям, среднее время удержания, число сделок. Ниже простая карточка на каждую позицию. Позиция открывается покупкой с нулевого остатка и закрывается, когда всё продано; повторная покупка того же токена — новая позиция, так что старый закрытый убыток не смешивается с новой сделкой. В каждой карточке:
  - статус ОТКРЫТА (зелёный) или ЗАКРЫТА (красный);
  - сумма позиции в NEAR и долларах: вложено и текущая стоимость (у закрытых — сколько выведено);
  - ТВХ по капитализации в долларах (средний вход по покупкам позиции) и капа сейчас, а у закрытых — на выходе;
  - реализованный и нереализованный PnL в NEAR и долларах, итог с процентом от вложенного;
  - остаток токенов, выплаты холдерам, время удержания, число покупок и продаж.

  Сортировка по дате открытия или по сумме (вложено); повторный клик — в обратном порядке. Карточки обновляются вживую по цене пула. В правой колонке только лента подписок.
- **Звук громче и дольше.** Три ноты через компрессор: у покупки восходящие, у продажи нисходящие.

## Возможности

- **Живая лента.** Каждые 3 секунды (настраивается) лёгкий RPC-запрос проверяет баланс кошелька. Любая его транзакция сжигает газ, поэтому изменение видно сразу, и приложение запрашивает новые транзакции. Раз в 15 секунд идёт страховочная проверка, которая ловит и чисто токенные поступления. Обычно событие появляется через 4–8 секунд после блока. Если receipts транзакции ещё исполняются, пост помечается «исполняется» и обновляется сам.
- **Подробности сделок.** Сумма в NEAR, количество токенов, налог токена (у токенов Nearly 1–2%), цена за токен, FDV в момент сделки, маршрут (`NEAR → NEARLY → NEARLEE`), пулы и комиссия, площадка (Rhea DCL / Rhea / NEAR Intents) и лаунчпад (Nearly и др.).
- **Живой PnL на покупках.** Пока кошелёк держит токен, пост о покупке обновляется каждые 3 секунды по цене пула Rhea DCL. Он показывает `+10% (+50 NEAR) ≈ +$235`: PnL в процентах, нереализованную прибыль в NEAR и эквивалент в долларах. Строка «Сейчас» показывает текущую цену, текущий FDV и изменение с момента сделки.
- **Закрытые сделки.** На продаже — реализованный PnL к средней цене входа в %, NEAR и долларах. На покупке уже закрытой позиции — итоговый PnL позиции в том же формате.
- **Вкладка «Сводка».** Выберите 24 часа, 7 или 30 дней и увидите PnL всех сделок за период. К реализованному PnL продаж прибавляется живой нереализованный PnL открытых позиций. Там же выплаты холдерам, итог с выплатами, объём покупок и продаж, число сделок, доля прибыльных продаж, лучший и худший токен и разбивка по токенам.
- **Неудачные сделки** объясняются простыми словами: проскальзывание, нехватка средств, ордер не исполнен из-за stop point.
- **Сигналы:** `storage_deposit` в токене (часто подготовка к покупке), новые ключи доступа и деплой контракта выделяются отдельно.
- **Оповещения.** Звук генерируется в браузере (Web Audio): у покупки тон восходящий, у продажи нисходящий, у ошибки предупреждающий. В заголовке вкладки появляется счётчик `(N)`, на иконке точка; уведомления на рабочий стол — по желанию. Опрос идёт через Web Worker, поэтому оповещения приходят и в фоновой вкладке. В настройках можно выбрать, о чём оповещать, и минимальный размер сделки.
- **Позиции и PnL** по токенам, **балансы кошелька**, **статистика**, **фильтры**, **поиск** (токен, хеш, аккаунт), **экспорт в CSV**. Частые мелкие выплаты холдерам подряд сворачиваются в одну карточку.
- **Язык:** английский (по умолчанию) или русский. **Тема:** как в системе, светлая или тёмная. Оба переключателя в настройках, выбор запоминается.

## Надёжность

- **Устаревший кеш больше не ломает сайт.** GitHub Pages кеширует файлы на 10 минут. У каждого модуля в адресе одна и та же метка-хеш содержимого (`?v=…`, её ставит `tools/stamp.py`), поэтому браузер никогда не смешивает старые и новые файлы.
- **«Сторож» загрузки.** `js/boot.js` проверяет, что приложение действительно запустилось. Если нет — один раз перезагружает страницу со свежим адресом, а если и это не помогло, вместо пустой страницы показывает, как обновить её принудительно.
- **Резервный источник данных.** Если API транзакций FastNEAR недоступен или ограничил запросы, лента переключается на NearBlocks (история) и RPC `EXPERIMENTAL_tx_status` (детали). Данные приводятся к тому же формату и разбираются тем же кодом, в статусе видно «резервный API». Когда FastNEAR вернётся, полная история тихо дозагрузится, без ложных оповещений.
- **Несколько RPC-провайдеров** (FastNEAR, dRPC, shitzuapes, архивный FastNEAR). Провайдер, который ошибается или ограничивает запросы, пропускается на минуту.

## Источники данных

Всё работает в браузере, сервер не нужен.

| Что | Откуда |
|---|---|
| История транзакций, receipts, логи | [FastNEAR Transactions API](https://tx.main.fastnear.com); резерв: NearBlocks + RPC |
| Баланс NEAR, метаданные токенов, состояние пулов DCL (живые цены) | NEAR RPC (ротация провайдеров) |
| Балансы токенов | FastNEAR API (`/v1/account/{id}/full`) |
| Данные запусков Nearly (цена, иконка, launch id → токен) | `nearly.trade/api` |
| Цены | Пулы Rhea DCL (вживую), Intear Prices, прайс-лист Rhea |
| Рейтинг трейдеров | Nearly (`/api/traders`, `/api/trader/{аккаунт}`), Intear Events API (свопы по токену и по трейдеру), список токенов Intear (цены, decimals), список пулов Rhea (объём за 24 часа) |

Суммы считаются по событиям NEP-141 (`ft_transfer`, `ft_mint`, `ft_burn`), текстовым логам wNEAR, событиям свапов Rhea DCL (`dcl.ref`) и Rhea v2 (`Swapped … for …`) и по депозитам receipts. Возвраты газа не учитываются.

## Разработка

Сборка не нужна: обычные ES-модули.

```bash
python -m http.server 8000
```

- **Приложение:** http://localhost:8000/
- **Тесты:** http://localhost:8000/tests/ (72 теста: парсер, оба языка, PnL и сводка, позиции, расчёт и движок рейтинга, конвертация резервного источника, правила оповещений, защита от XSS). Папки `tests/` и `tools/` на Vercel не выкладываются (см. `.vercelignore`).

Перед каждым коммитом проставьте версии модулей:

```bash
python tools/stamp.py
```

## Ограничения

- **Длинная история.** Для аккаунтов с историей больше 1000 транзакций сразу загружаются последние 200, остальные — кнопкой «Загрузить более ранние». PnL и сводка считаются по загруженной истории.
- **Доллары** считаются по текущему курсу NEAR.
- **Глубина рейтинга.** Публичный API Intear отдаёт последние 50 свопов по токену или кошельку, поэтому на других площадках рейтинг лучше всего видит недавнюю активность; у очень активных кошельков старые позиции могут не попасть. Цифры Nearly берутся у самого Nearly и полные. При каждом обновлении сканируются 20 самых торгуемых мемов вне Nearly.
- **В резервном режиме** видны только транзакции примерно 25 последних receipts, пока FastNEAR не вернётся.
- **Браузерный ключ FastNEAR.** Чтобы снять анонимный лимит FastNEAR, создайте бесплатный *браузерный* ключ с привязкой к своему домену (https://docs.fastnear.com/auth) и впишите его в `FASTNEAR_API_KEY` в `js/config.js`.
